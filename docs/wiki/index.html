a2a-mod

A Claude Code mod that lets Claude hand tasks to non-Claude worker agents over the Agent2Agent protocol (1.0 and 0.3), carry on working, and pick the results up when they land.

/plugin marketplace add NovusEdge/a2a-mod
/plugin install a2a-mod@a2a-mod
/a2a add https://your-worker.example

Needs Claude Code 2.1.287 or later. Docs are on the way; until then, see the repository.
